# Prompts para as novas ilustrações

Cada prompt abaixo é completo: já inclui o estilo. Copie e cole um de cada vez no
Nano Banana (de preferência numa única conversa, para manter o personagem). Nos
prompts com personagem, anexe junto a foto `images/robert-lowell-elsa-dorfman.jpg`
(Elsa Dorfman, CC BY-SA 3.0, Wikimedia Commons). Formato: 16:9. Salve cada imagem
com o nome entre colchetes e coloque em `Robert_Lowell_Book_Project/images/`.
Depois, eu encaixo no projeto e reconverto.

Regras em todos: sem texto, letras, assinatura ou marca d'água; traço realista a
pena e aquarela, como nas ilustrações antigas; personagem com o rosto da foto de
referência, nunca caricatura; tom calmo e respeitoso.
